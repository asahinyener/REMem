Recursive RLMs over a Temporal Knowledge Graph

A small exploratory ReMem fork showing how a DSPy RLM can decompose a temporal KGQA question, let child branches gather graph evidence, and aggregate intervals in a Python REPL.

This is a pedagogical artifact. It does not claim a new method or benchmark result. The goal is to make the agent trace easy to inspect.

The Question

TimelineKGQA CRON question 25107 asks:

During which period did Andre Hahn serve as a member of the German Bundestag
while Jason Shackell was a member of Burnley F.C.?

The answer is the overlap between two temporal facts:

Andre Hahn -> German Bundestag:
2013-01-01 to 2017-01-01

Jason Shackell -> Burnley F.C.:
2012-01-01 to 2015-01-01

overlap:
2013-01-01 to 2015-01-01

Final answer: (2013-01-01, 2015-01-01)

Pipeline

1. Load one TimelineKGQA CRON question and its supporting temporal KG events.
2. Convert KG facts into short temporal sentences that ReMem can index.
3. Build a temporal memory graph with fact nodes, entity nodes, and temporal qualifiers.
4. Run a DSPy RLM controller over ReMem graph tools.
5. Use llm_query_batched to spawn branch RLMs for independent temporal lookups.
6. Store branch evidence in the parent REPL and compute the interval intersection with Python.

What Changed

Temporal Graph Fixes Fact hashing, entity-fact edges, store selection, and igraph attribute access.
DSPy Graph Agents ReAct and RLM wrappers over ReMem's existing graph tools.
OpenAI API Path Explicit key/base-url resolution for chat and embedding clients.

Reproduce

First run the no-API preflight:

PYTHONDONTWRITEBYTECODE=1 \
PYTHONPATH=src \
python examples/timelinekgqa/check_reproduction.py

Then run the full API path:

PYTHONPATH=../external/dspy_recursive:src \
TIMELINEKGQA_DATASET_DIR=../external/timelinekgqa/Datasets \
TIMELINEKGQA_QUESTION_ID=25107 \
TIMELINEKGQA_RLM_SUBLM_DEMO=true \
AGENT_MAX_STEPS=8 \
RLM_MAX_TOKENS=8192 \
python examples/timelinekgqa/run_timelinekgqa_temporal_rlm_trace.py
